# 小型办公室/企业级分层网络架构

> 本文档由《网吧分层网络架构》方案整体适配而来：架构分层逻辑（出口层-核心层-接入层）完全一致，设备与场景按**小型办公室（约 30–50 人规模）**重做，并保留「监控系统接入、无线 AP、门禁管理」等扩展子主题的完整问答。拓扑图见同目录文件《小型办公室网络拓扑图.html》。

## 网络拓扑（示意图）

```
Internet（运营商宽带，可双线路冗余）
  │
企业VPN路由器 TL-ER5120G（出口层：NAT / 多WAN / VPN / 带宽管理 / 防火墙）
  │
核心交换机 TL-SH7428（核心层：VLAN间路由 / DHCP / ACL / QoS / 堆叠）
  ├────────────┬────────────┬────────────┬─────────────┐
办公接入交换机    PoE交换机       监控接入交换机    门禁接入交换机        服务器/NAS
TL-SG2226       TL-SG2008P      TL-SG2226         TL-SG2226            （VLAN 50）
（VLAN 10）      （VLAN 20/30）  （VLAN 100）      （VLAN 40）           文件共享/备份
  │               │               │               │
办公PC/打印机    吸顶式AP          NVR             门禁一体机/电锁
（有线）         （员工/访客SSID） 摄像头(PoE)      （人脸/刷卡）
```

### 一、出口与边缘层设备（顶层）

**1. Internet（互联网）**

* **功能**：外部网络接入点，为整个办公室提供访问外网的通道。
* **建议**：小型办公室至少申请 1 条企业宽带（如 500M–1000M 下行 / 50M–100M 上行）；对在线办公、视频会议、云服务依赖高的团队，可再申请 1 条备用线路，配合路由器双 WAN 做负载均衡和故障切换。

**2. 企业级 VPN 路由器（推荐型号：TL-ER5120G）**

* **功能**：整个网络的**网关和出口边界**。
* **核心作用**：
  * **多线路接入与负载均衡**：双 WAN 口，可接入两条宽带，实现流量均衡和线路备份。
  * **网络地址转换（NAT）**：让内网设备共享公网 IP 上网。
  * **VPN 服务（小型办公室核心需求）**：支持 IPSec / L2TP / PPTP。员工出差、居家办公时拨入 VPN，等同身在内网，可安全访问文件服务器、NAS 和内部业务系统，避免把办公资源直接暴露在公网。
  * **带宽管理与行为控制**：弹性带宽控制、连接数限制，防止大流量下载、在线视频等抢占会议与核心业务带宽。
  * **安全防护**：内外网 IP/MAC 绑定、防 ARP 攻击、内置简单防火墙（ACL）。

**3. 独立防火墙 / 上网行为管理（可选）**

* **功能**：对涉及财务、客户隐私数据的办公室，可在路由器后增加独立防火墙/UTM 设备，做应用识别、上网行为审计与更细的访问控制。小型办公室通常由路由器内置安全功能承担即可，按预算与合规要求决定。

**4. 服务器群（办公室核心业务支撑）**

* **NAS / 文件服务器**：集中存放办公文档、设计素材、项目资料，支持账号权限管理（如群晖、威联通或普通 PC 搭 Samba）。
* **打印服务器**：统一管理网络共享打印机（多数打印机支持直连网络，可不单设）。
* **DHCP / DNS**：核心交换机已内置 DHCP，服务器无需重复部署；如需 Windows 域环境（AD）可增加域控服务器统一账号管理。
* **备份**：由 NAS 定时备份重要电脑数据与业务系统，防止勒索病毒与误删。

### 二、核心层设备（中间层）

**5. 三层网管核心交换机（推荐型号：TL-SH7428）**

* **功能**：整个局域网的**数据交换枢纽（核心骨干）**。
* **核心作用**：
  * **高速转发**：4 个万兆 SFP+ 端口 + 24 个千兆端口，负责汇聚接入层所有交换机的流量，并高速转发至路由器与服务器群。
  * **VLAN 间路由与 DHCP**：支持静态路由、OSPF、RIP，为每个 VLAN 配置网关并下发 IP，实现不同区域逻辑隔离、按需互通。
  * **高级安全与认证**：四元绑定、ARP/IP/DoS 防护、802.1X 认证。
  * **高可用性**：支持最多 8 个单元堆叠，支持 VLAN、QoS、ACL，保障核心网络稳定。

**小型办公室 VLAN 规划参考表**

| VLAN | 用途 | 网段 | 网关（核心交换机接口） | 策略要点 |
| :--- | :--- | :--- | :--- | :--- |
| 10 | 办公有线（PC/打印机/会议设备） | 192.168.10.0/24 | 192.168.10.1 | 最高优先级，互访自由 |
| 20 | 无线办公（员工笔记本/手机） | 192.168.20.0/24 | 192.168.20.1 | 可访问办公资源，限制下载带宽 |
| 30 | 访客无线 | 192.168.30.0/24 | 192.168.30.1 | 仅可上网，ACL 禁止访问内网 |
| 40 | 门禁 / IoT | 192.168.40.0/24 | 192.168.40.1 | 仅授权设备可访问 |
| 50 | 服务器 / 管理 | 192.168.50.0/24 | 192.168.50.1 | 管理网段，ACL 收紧 |
| 100 | 监控 | 192.168.100.0/24 | 192.168.100.1 | 禁止被办公/访客主动访问 |

### 三、接入层设备（下层）

**6. 网管接入交换机（推荐型号：TL-SG2226）与 PoE 交换机（TL-SG2008P）**

* **功能**：直接连接终端设备，是**终端的接入点**。
* **核心作用**：
  * **终端接入**：TL-SG2226 提供 24 个千兆 RJ45 端口连接办公电脑与打印机；PoE 交换机（8 口 TL-SG2008P 或 24 口 TL-SG2226P）通过一根网线同时为吸顶 AP、网络摄像头、门禁一体机供电，简化布线。
  * **VLAN 隔离**：支持 802.1Q VLAN、端口 VLAN，把办公、无线、监控、门禁划分在不同广播域，防止广播风暴与 ARP 欺骗。
  * **接入控制与安全**：支持 QoS、带宽控制、风暴抑制、端口汇聚、端口镜像、环回保护，保障每个端口安全稳定。
  * **管理**：支持 Web 管理，方便运维排障。

### 四、终端用户区域（底层）

**7. 办公区 / 无线办公区 / 访客区 / 共享设备**

* **功能**：不同角色的终端接入区域，通过网络核心与接入交换机的 **VLAN 划分** 和 **QoS 带宽策略**，为各区域分配不同的优先级、带宽限制与安全策略：
  * **办公区（VLAN 10）**：员工工位 PC、笔记本有线接入，享受最高带宽与最低延迟，保障视频会议、ERP/财务系统流畅。
  * **无线办公区（VLAN 20）**：吸顶式 Wi-Fi 6 AP 覆盖，员工移动设备接入，限速但可访问办公资源。
  * **访客区（VLAN 30）**：独立 SSID + 独立 VLAN，仅开放上网、禁用内网访问，配合 Portal 认证防止被蹭网。
  * **共享设备**：网络打印机、投影、会议大屏归入办公 VLAN 统一管理。
  * **监控（VLAN 100）**：仅需出口带宽用于远程查看，限制上行速率，避免视频流挤占办公带宽。

### 总结：方案整体设计逻辑

该方案采用「**核心 + 接入**」两层架构（与网吧方案同构）。出口路由器负责**流量调度、VPN 接入与安全防御**；核心交换机负责**高速转发、VLAN 间路由与全局安全策略**；接入交换机负责**终端隔离与端口安全**。整体突出「**远程办公 VPN、VLAN 精细隔离、带宽可控**」的小型办公室特色。

## 如果有另外一整套监控系统（新增 TL-SG2226 + NVR），利用以上系统如何接入现有网络

最佳实践与网吧方案一致：**将监控系统作为独立网络区域（VLAN 100）接入核心交换机（TL-SH7428）**。既能保证监控数据高速传输，又与办公网（VLAN 10/20/30）安全隔离，避免视频流占用办公带宽或引发广播风暴。

### 一、物理连接拓扑

1. **上行连接**：用一根网线，将新增 **TL-SG2226（监控接入交换机）** 的任意千兆端口，连接到 **核心交换机（TL-SH7428）** 的空闲千兆端口。
2. **NVR 连接**：将 **NVR（网络硬盘录像机）** 连接到新增 TL-SG2226 的端口。
3. **摄像头连接**：将网络摄像机（IPC，建议 PoE 款）连接到 TL-SG2226 剩余端口，或直接用 PoE 交换机供电。（NVR 如需本地画面，显示器接 NVR 的 HDMI/VGA 口即可。）

### 二、网络逻辑规划（VLAN 与 IP 划分）

- **办公业务 VLAN**：例如 VLAN 10/20（现有网络）。
- **监控专用 VLAN**：例如 **VLAN 100**（新增）。
- **监控网段**：例如 `192.168.100.0/24`，NVR 与摄像头均使用该网段 IP。

### 三、设备配置步骤

1. **核心交换机（TL-SH7428）**
   - 创建 VLAN 100；将连接监控交换机的端口配置为 Trunk（或 Access 划入 VLAN 100）。
   - 为 VLAN 100 配置虚拟接口 IP（如 `192.168.100.1`）作为监控网络网关。
   - 开启 DHCP（可选）；更简单的是由 NVR 自带 DHCP 为摄像头分配 IP（推荐后者）。
   - 确认核心交换机已有指向路由器（TL-ER5120G）的默认路由。
2. **监控接入交换机（新增 TL-SG2226）**
   - 将连接 NVR 和摄像头的端口全部划入 **VLAN 100**。
   - 上行口配置为 Trunk，允许 VLAN 100 通过。
   - 开启环回保护，防止摄像头线路短路导致网络瘫痪。
3. **NVR 配置**
   - NVR IP 设为监控网段（如 `192.168.100.2`），网关指向核心交换机 VLAN 100 接口（`192.168.100.1`）。
   - 在 NVR 中一键添加或手动添加摄像头 IP，进行录像与画面管理。

### 四、出口网络（互联网）访问配置

- 仅在办公室内查看监控，以上步骤已完成。
- 如需**外部（手机 APP、异地分公司）**查看：
  1. **端口映射**：在路由器虚拟服务器中，将 WAN 口某端口（如 8000）映射到 NVR 对应端口（HTTP 80 / RTSP 554）。
  2. **动态 DNS（DDNS）**：办公室宽带多为动态公网 IP，在路由器开启 TP-LINK DDNS 绑定域名，方便远程访问。
  3. **VPN（更安全，推荐）**：办公室员工本来就要用 VPN，直接拨入 VPN 后输入 NVR 内网 IP 即可查看，避免把 NVR 暴露公网。

### 五、安全与优化建议

1. **修改默认密码**：摄像头与 NVR 务必改默认密码，防止弱口令扫描入侵。
2. **带宽控制**：在核心交换机上对 VLAN 100 做 QoS 限速，防止 NVR 远程回传占满出口上行带宽，导致办公视频会议卡顿。
3. **UPS 供电**：监控系统与核心网络设备建议接入 UPS，防止断电损坏硬盘或中断监控。

**总结**：新增 TL-SG2226 接在核心交换机上，划分独立 VLAN 100，NVR 与摄像头接在其下，由核心交换机做网关、出口路由器做端口映射或 VPN，即可无缝融入现有网络并实现远程访问。

## 监控无须在局域网内查看，利用 P2P/云服务（最简单）进行录像查看

### 核心思路

**物理上挂载在核心交换机，逻辑上划分独立 VLAN，网络出口借用办公室路由器上网，远程查看依赖 NVR 自带的 P2P 云服务。**

### 第一步：物理连接（硬接线）

1. **监控系统内部组网**：所有 PoE 摄像头与 NVR 接入新增的 TL-SG2226；NVR 负责录像存储与云服务对接。
2. **接入现有网络**：将新增 TL-SG2226 通过一根网线接入核心交换机（TL-SH7428）的空闲千兆端口（不要直连路由器 LAN 口，接核心可保证内网监控流量高速转发）。

### 第二步：网络逻辑配置（划分 VLAN 隔离）

1. **核心交换机（TL-SH7428）**
   - 创建 VLAN 100（命名 Monitoring）；连接监控交换机的端口设为 Access 并划入 VLAN 100。
   - 为 VLAN 100 配置网关 IP（如 `192.168.100.1/24`），并开启 DHCP 或中继。
2. **监控接入交换机（TL-SG2226）**：保持默认即可（作为二层交换机使用）；建议在 NVR/摄像头设置固定 IP。
3. **路由打通（核心到出口）**
   - 核心交换机默认路由指向办公室路由器（TL-ER5120G）内网 IP。
   - 路由器配置回程静态路由：目的网段 `192.168.100.0/24`，下一跳指向核心交换机互联 IP（若核心交换机支持 VLAN 100 的 NAT，也可由核心直接 NAT 后送路由器）。

### 第三步：实现「无须局域网内查看」与「P2P 云服务」

1. **NVR 网络设置**：IP 设为 `192.168.100.x`，网关 `192.168.100.1`，**DNS 必须填公网 DNS（如 223.5.5.5 或 114.114.114.114）**——这是 P2P 能否成功的关键。
2. **开启 P2P 云服务**：在 NVR「网络设置 → P2P / 云服务」中启用（海康萤石云、大华乐橙、TP-LINK 物联等），NVR 会自动向外网发起 P2P 穿透连接。
3. **手机远程查看**：手机下载对应品牌 APP，注册登录并扫码/输入序列号绑定，即可在外网随时查看实时画面与回放，**完全不需要做端口映射**。
4. **关闭内网访问（可选加固）**：在核心交换机配置 ACL，禁止办公网段主动访问监控网段、但允许监控网段访问外网，办公电脑完全无法扫描监控设备，保障隐私安全。

### 第四步：办公室环境下的重要优化与注意事项

1. **上行带宽限速（非常重要）**：远程查看监控消耗**上行带宽**。在核心交换机或路由器上对 NVR 的 IP 做上行限速（建议 2–4 Mbps，足够看主/子码流），防止远程查看导致视频会议卡顿。
2. **NVR 双网口隔离（如有）**：一个网口接监控交换机（摄像头网段），另一个接办公核心交换机（用于上外网），物理层彻底隔离。
3. **DNS 排查**：APP 显示「设备离线」时，90% 是 NVR 的 DNS 没设对或路由器未放行 NVR 出网权限；确保 NVR 能 ping 通外网。
4. **防攻击策略放行**：若路由器防攻击策略把 NVR 的 P2P 打洞流量误判拦截，将其加入白名单。

**总结拓扑变更**：`Internet` → `办公室路由器(TL-ER5120G)` → `核心交换机(TL-SH7428)` →（VLAN 100 隔离）→ `监控接入交换机(TL-SG2226)` → `NVR + 摄像头` → **NVR 通过 P2P 穿透至公网，手机 APP 远程查看**。

## 监控用的 TL-SG2226 可以不经过核心交换机，直接连接路由器吗

**可以，物理上完全可以直连。** TL-ER5120G 路由器带有 2 个 WAN 口和多个 LAN 口。

### 一、直连路由器的优势

1. **减轻核心交换机负担**：监控内部视频流（摄像头→NVR）只在新增 TL-SG2226 内部转发，不占用核心交换机背板带宽。
2. **架构最简单**：独立一套系统直接挂在出口路由器上，逻辑清晰、排障简单。
3. **不受办公内网影响**：即使办公网（核心交换机或接入交换机）出故障，监控系统仍可独立运行并上外网。

### 二、直连路由器的硬性条件与限制

1. **路由器端口数量够不够（首要问题）**：TL-ER5120G 为双 WAN 路由器。若已用双宽带（占 2 个 WAN 口）、再连核心交换机（占 1 个 LAN 口），通常仍剩 2–3 个 LAN 口，接监控交换机一般够用；不够则接回核心交换机。
2. **路由器的 VLAN / 多子网隔离能力**：直连后若路由器不做隔离，监控设备与办公电脑会处于**同一广播域**，员工电脑可能扫描到监控设备，违背隔离初衷。要求路由器支持多网段 LAN（如 LAN1 办公 `192.168.10.x`、LAN2 监控 `192.168.100.x`）或 802.1Q VLAN。
3. **性能瓶颈（影响不大）**：摄像头→NVR 流量不经过路由器；仅外网 P2P 远程查看时 NVR 请求出网流量，对 NVR 的 IP 做上行限速（2–4 Mbps）即可，路由器完全扛得住。

### 三、如果决定直连，配置步骤建议

1. **物理连接**：将监控交换机 TL-SG2226 接入 TL-ER5120G 的空闲 LAN 口。
2. **网络划分**：若路由器支持多 LAN/VLAN，将接监控的端口单独划为 VLAN（如 VLAN 100，网段 `192.168.100.1/24`），NVR 网关指向该网段网关；若不支持 VLAN，只能共用一个网段，则必须用 ACL 禁止办公网段访问 NVR IP、允许 NVR 访问外网。
3. **NVR 设置**：手动设置 IP（对应网段）、网关、公网 DNS（如 223.5.5.5），开启 P2P 云服务。
4. **路由器限速**：带宽控制中针对 NVR IP 限制上行带宽（2–4 Mbps）。

### 💡 最终建议：哪种方案更适合你？

* **选择直连路由器（TL-ER5120G）**：路由器有空闲端口，且支持多网段/VLAN，想少在核心交换机上配置时。
* **选择接核心交换机（TL-SH7428，原方案）**：希望严格的 VLAN 隔离、不想占用路由器端口，或后续监控点位会持续扩充时。核心交换机做 VLAN 划分和 ACL 更专业，路由器专心做 NAT 出口与 VPN。

**建议**：先看路由器剩余空闲网口数。只有 1 个且还需保留冗余，就接核心交换机；网口够且支持多 LAN 隔离，直连最省事。

# 在现有设备上，如果我想加入无线 AP 满足办公室的无线上网需求，该如何选择

在现有网络基础上增加无线 AP，核心是**利用 TL-SH7428 核心交换机的三层管理能力，搭配 AC 控制器统一管理，并选择支持 PoE 供电的 AP 与交换机简化部署**。小型办公室建议**直接选择 Wi-Fi 6 的吸顶式 AP**，避免终端升级后出现性能瓶颈。

### 🎯 第一步：无线 AP 选型要点

* **无线协议**：首选 **Wi-Fi 6（802.11ax）**，高密度接入、多设备并发和低延迟方面优势明显，能满足会议室视频、多人同时在线办公。
* **带机量**：普通双频 AP 推荐接入 **30–40 人**，高密度四频 AP 可达 **400 个**客户端。按办公室各区域人数规划 AP 数量（一般 30–50 人办公室 2–4 台 AP 足够）。
* **频段与速率**：选择**双频** AP，开启 **5GHz 优先**，避开 2.4GHz 干扰；速率至少 AX3000（约 3000Mbps）级别。
* **供电方式**：务必支持**标准 PoE 供电（802.3af/at）**，一根网线同时传输数据与供电，安装简单。
* **安装方式**：**吸顶式**为商业办公首选，外观整洁、覆盖均匀。

### 📋 第二步：TP-LINK AP 型号推荐

| 推荐型号 | 无线协议 | 关键特性 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **TL-XAP3007GC-PoE/DC 易展版** | Wi-Fi 6 | AX3000 双频，易展 MESH 组网，吸顶式，PoE 供电 | 开放办公区、会议室 |
| **TL-HDAP2600GC-PoE/DC** | Wi-Fi 5 (AC) | 四频高密度 AP，最大关联 **400** 客户端 | 大会议室、高密度工位区 |
| **TL-7AP3600HC-POE/DC** | Wi-Fi 7 | BE3600 双频，2.5G 上行口，面向未来预留带宽 | 追求极致性能的区域 |

### 🛠️ 第三步：部署方案与 AC 控制器选择

**1. 推荐部署架构**

* **物理连接**：新采购的 **PoE 交换机**（用于给 AP 供电）通过网线连接 TL-SH7428 核心交换机空闲端口；AP 接入 PoE 交换机。
* **逻辑规划**：
  * 在 TL-SH7428 上为无线网络创建独立 VLAN（如 **VLAN 20**，网段 `192.168.20.0/24`），实现与有线办公网逻辑隔离；访客再划 VLAN 30。
  * 配置 TL-SH7428 作为无线 VLAN 网关并启用 DHCP；配置 ACL：无线员工 VLAN 可访问办公资源，访客 VLAN 仅允许上网。

**2. AC 控制器选择**

* **方案 A：独立 AC 控制器（推荐）**：购买独立 AC（如 **TL-AC200 / TL-NAC1000**）**旁挂**在 TL-SH7428 上，无需改变现有架构，自动发现并统一管理 AP，支持 SSID 与 VLAN 映射。
* **方案 B：软件 AC（Omada）**：在办公室服务器/PC 上安装 Omada 软件控制器集中管理 AP，无需额外硬件，但需要一台常开设备。

**3. PoE 交换机选择**

* 根据 AP 数量选**全千兆 PoE 交换机**（如 **TL-SG2226P**，24 口 PoE+，整机功率 225W；少量 AP 可选 8 口 TL-SG2008P）。

### ⚠️ 第四步：注意事项

* **带宽规划**：无线网络与有线网络共享出口带宽，建议在 TL-ER5120G 上对无线 VLAN 限速，保障视频会议等核心业务。
* **信道与功率优化**：在 AC 控制器启用**射频调优**，自动分配最优信道与发射功率，减少 AP 间干扰。
* **安全认证**：启用 **Portal 认证**（Web 认证）或微信连 Wi-Fi，访客需输入验证码/关注公众号上网，防蹭网并留存记录。
* **VLAN 隔离**：严格隔离无线 VLAN 与办公有线 VLAN，防止无线用户访问办公室管理与服务器网段。

### 💎 总结

升级路径非常清晰：**利用 TL-SH7428 的三层能力做 VLAN 隔离，购买一台独立 AC 控制器（如 TL-AC200）旁挂管理，再配一台 PoE 交换机给 Wi-Fi 6 吸顶 AP 供电**。既能满足员工与访客的无线上网需求，又保证有线网络稳定和办公信息安全。

# "安全认证：建议启用 Portal 认证或微信连 Wi-Fi"，以上方式在哪里配置

主要是在 **AC 控制器** 的管理后台配置，核心路径为 **「认证管理」→「Portal 认证」** 或 **「认证管理」→「认证服务器」**。具体位置视 AC 方案不同：

### 📍 方案一：独立硬件 AC 控制器（如 TL-AC200 / TL-AC1000）

1. **登录 AC 控制器**：确保 AC 自身网关与 DNS 正确、能上网。
2. **设置跳转页面**：进入「认证管理」→「Portal 认证」→「跳转页面」，自定义标题、欢迎信息、背景图。
3. **配置认证参数**：「认证管理」→「Portal 认证」→「认证参数」，设置认证老化时间、认证模式（按 SSID 或 VLAN）。
4. **启用认证服务**：
   * **Portal 认证**：配置为「Web 认证」，用户连 Wi-Fi 后输入账号密码上网。
   * **微信连 Wi-Fi**：选择「微信连 Wi-Fi」，关联跳转页面，指定需认证的 VLAN/SSID，设置免费上网时长。
5. **关联无线服务**：将认证方式绑定到需要认证的无线 SSID 上。

### 💻 方案二：Omada 软件控制器

1. 登录 Omada 控制器，进入 **「设置」→「认证」→「Portal」**。
2. 新建 Portal 配置，选择认证类型（Web 认证 / 微信认证），关联生效的 SSID 与网络。
3. 如需外部 Radius 服务器，在「设置」→「认证」→「认证服务器」中预配置。
4. 在无线网络设置中，将 Portal 认证绑定到对应 SSID。

### ⚠️ 关键注意事项

* **设备兼容性**：较早的 TL-AC100 / TL-AC200 可能**不支持 Portal 认证**，购买前确认型号。
* **微信公众号准备**：微信连 Wi-Fi 需拥有微信公众号，并在公众平台添加「微信连 Wi-Fi」插件、录入设备，获取门店 Wi-Fi 信息。
* **认证链接配置**：将 AC 生成的认证链接（如 `http://ac.tplogin.cn:8080/wechatv2/?auth_token=...`）配置到公众号自动回复中，用户才能完成认证。
* **触发方式**：手机连 Wi-Fi 后需打开浏览器访问 **HTTP** 网站才会弹出 Portal 页；HTTPS 网站可能无法自动重定向。

# 如果我想为小型办公室加入门禁管理，需要加入哪些新设备

为办公室加入门禁管理，本质是构建一套**身份核验与自动化出入控制系统**：用**人脸识别/刷卡门禁终端**联动**电控门锁**，接入现有网络架构，实现人员出入的规范化管理与考勤联动。

### 🧩 核心设备清单

| 设备类别 | 核心功能 | 推荐/可选型号参考 |
| :--- | :--- | :--- |
| **智能门禁一体机** | 身份核验（人脸/刷卡/密码），控制门锁开关 | TP-LINK **TL-AS7230** 系列（7 寸屏）；或斯科德 M302、泰首智能 IDC7708T2 等 |
| **门禁控制器** | 核心处理单元，连接读卡器、电锁、出门按钮 | 单门/双门/四门网络控制器（如 WEDS-WA102、WA401 等） |
| **电控门锁** | 接收控制器信号，执行开门/锁门 | **磁力锁**（玻璃门/木门）、**电插锁**（铝合金门） |
| **门禁专用电源** | 为电锁与控制器提供稳定不间断供电 | 12V/3A 或 5A 门禁电源（带 UPS 功能） |
| **出门按钮** | 内部手动开门 | 标准 86 型出门按钮 |
| **门磁** | 检测门开关状态，判断非法开门/久未关门 | 与控制器配套 |
| **PoE 交换机** | 为门禁一体机等提供网络与 PoE 供电 | 已有 TL-SG2226 或新增 PoE 交换机（TL-SG2008P 等） |

### 🔗 网络集成与 VLAN 规划

1. **创建独立 VLAN**：在核心交换机 TL-SH7428 上创建 **VLAN 40**（网段 `192.168.40.0/24`）专用于门禁系统。
2. **端口划分与连接**：连接门禁设备的交换机端口划入 VLAN 40；门禁控制器/一体机接该端口并设静态 IP（如 `192.168.40.x`）。
3. **路由与访问控制**：配置 VLAN 间路由，允许门禁 VLAN 访问互联网（云服务、时间同步）；配置 ACL **禁止**办公内网其他 VLAN 主动访问门禁 VLAN，防止员工扫描或攻击门禁设备。
4. **供电考虑**：门禁一体机支持 PoE 则接 PoE 交换机；否则单独提供 DC 12V 电源。

### 🚨 联动与应急设备（办公室同样需要）

* **一键报警/紧急开门按钮**：办公室出入口安装，紧急情况可一键开门或联动报警，是安全兜底。
* **消防联动**：门禁系统与消防报警联动，火警时电锁自动断电、门可自由推开（**消防安全必备，务必接线测试**）。
* **监控联动**：将门禁事件（非法闯入、门长时间未关）与现有 NVR 监控联动，自动抓拍录像，方便事后追溯。

### 💡 实施步骤建议

1. **设备选型与采购**：根据门点数确定控制器门数与电锁类型（办公室一般 1–3 个门）。
2. **网络规划与配置**：按上述 VLAN 40 方案在核心交换机完成创建、端口划分与 ACL。
3. **硬件安装与接线**：安装门禁一体机、电锁、出门按钮、门磁，接入网络与电源。
4. **软件配置与联调**：
   * 在门禁管理软件中配置人员权限（员工、访客、临时授权）。
   * 设置开门时段（如非工作时间仅授权人员进入）。
   * **与考勤系统对接**：实现「刷脸/刷卡打卡」，员工出入记录自动同步考勤。
   * 测试紧急开门、消防联动等功能。

### 💎 总结

为办公室增加门禁，核心是**智能门禁一体机 + 电控锁 + 独立 VLAN 40 隔离**，并务必部署**消防联动与紧急开门按钮**作为安全兜底，与监控、考勤系统做好联动。这样既实现人员出入规范化管理，又保障办公资产与信息安全。
