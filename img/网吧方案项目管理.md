# XX网吧一体化建设与无人值守改造项目管理方案

## 一、项目概况

**项目名称**：XX网吧分层网络、监控、无线、门禁一体化建设项目  
**建设性质**：现有网吧网络升级 + 无人值守改造  
**项目目标**：
1. 完成80台PC千兆有线接入，划分普通区、游戏区、VIP区，保障游戏低延迟。
2. 新增15路监控，NVR本地录像，支持P2P/云服务远程查看。
3. 新增5个室内Wi-Fi 6 AP，满足客人无线上网，支持Portal/微信连Wi-Fi认证。
4. 新增1套门禁管理，支持人脸/身份证核验，为无人值守做准备。
5. 监控、门禁、无线、网吧业务逻辑隔离，保障安全与带宽。
6. 出口通过TL-ER5520G统一上网，核心TL-SH7428做三层网关与VLAN隔离。

**建设原则**：出口层—核心层—接入层分层架构；安全隔离；带宽精细化控制；可远程运维；可扩展。

## 四、技术方案摘要与规模规划

### 1. 拓扑结构
`Internet → TL-ER5520G路由器 → TL-SH7428核心交换机 → 各接入交换机/服务器/监控/无线/门禁`

- 80台PC：建议用 **4台TL-SG2226**，每台约20台PC，留4口冗余。
- 15路监控：新增 **1台PoE交换机 + 1台NVR**，接核心交换机。
- 5个AP：新增 **1台PoE交换机 + 1台AC控制器**，AP吸顶安装。
- 1套门禁：门禁一体机、电锁、门禁电源、出门按钮、门磁、一键报警。
- 服务器群、公安监控设备接核心交换机。

### 2. VLAN与IP规划建议

| VLAN | 用途 | 网段 | 网关 |
|---|---|---|---|
| VLAN 10 | 普通上网区 | 192.168.10.0/24 | 192.168.10.1 |
| VLAN 20 | 游戏区 | 192.168.20.0/24 | 192.168.20.1 |
| VLAN 30 | VIP区 | 192.168.30.0/24 | 192.168.30.1 |
| VLAN 40 | 无线访客 | 192.168.40.0/24 | 192.168.40.1 |
| VLAN 50 | 服务器/管理 | 192.168.50.0/24 | 192.168.50.1 |
| VLAN 100 | 监控 | 192.168.100.0/24 | 192.168.100.1 |
| VLAN 200 | 门禁 | 192.168.200.0/24 | 192.168.200.1 |

核心交换机TL-SH7428作为各VLAN网关，默认路由指向TL-ER5520G；路由器配置回程静态路由。监控NVR网关指向192.168.100.1，DNS填223.5.5.5，开启P2P云服务。门禁VLAN通过ACL禁止网吧PC访问，但允许门禁出网。

### 3. 主要设备清单

| 设备 | 数量 | 说明 |
|---|---:|---|
| TL-ER5520G | 1 | 出口路由、多WAN、NAT、限速 |
| TL-SH7428 | 1 | 核心交换机，VLAN/路由/ACL |
| TL-SG2226 | 4 | 80台PC接入 |
| TL-SG2226/PoE交换机 | 1-2 | 监控、AP、门禁接入 |
| AC控制器 | 1 | TL-AC200/TL-NAC1000，管理5个AP |
| 室内AP | 5 | Wi-Fi 6吸顶AP，PoE供电 |
| NVR | 1 | 15路接入，按30天存储配硬盘 |
| 摄像头 | 15 | 网络IPC，建议PoE |
| 门禁一体机 | 1 | 人脸/身份证/刷卡 |
| 电锁、门禁电源、按钮、门磁 | 1套 | 门禁联动 |
| 一键报警对讲 | 1 | 无人值守安全兜底 |
| UPS、机柜、线材 | 1批 | 供电与布线 |

> 存储估算：15路×4Mbps×24h×30天≈19TB；若按2Mbps子码流存储约9.5TB。建议NVR配足硬盘并留冗余。

## 八、质量与测试标准

必须形成测试报告：
1. 80台PC千兆到桌面，内网延迟正常。
2. VLAN隔离：PC不能访问监控、门禁VLAN。
3. 出口NAT正常，多WAN切换正常。
4. 监控15路在线，录像保存≥30天，手机P2P远程可看。
5. NVR上行限速2-4Mbps，避免影响游戏。
6. 5个AP覆盖达标，漫游正常，Portal/微信认证可用。
7. 门禁识别≤1秒，非法闯入报警，消防联动断电开门。
8. UPS断电续航测试。
9. 配置备份、标签、文档齐全。

## 九、主要风险与应对

| 风险 | 应对 |
|---|---|
| 路由器端口不足 | 监控/无线/门禁优先接核心交换机 |
| 监控占用上行带宽 | 对NVR上行限速2-4Mbps |
| P2P远程离线 | 检查NVR DNS、网关、路由器白名单 |
| VLAN隔离不严 | 核心ACL禁止PC访问监控/门禁 |
| 无线干扰 | AC开启射频调优，5GHz优先 |
| 门禁被攻击 | 独立VLAN、强密码、禁止公网映射 |
| 消防联动失效 | 门禁电源接消防联动，火警断电开门 |
| 公安合规 | 上网日志、监控留存按当地网安要求 |
| 施工影响营业 | 分区分时施工，夜间割接 |
| 预算超支 | 变更单控制，预备费5-10% |

## 关键路径与缓冲建议

**关键路径**：  
设计确认 → 采购到货 → 布线完成 → 安装完成 → 配置联调 → 试运行 → 终验通过。

**最易延误环节**：采购到货。  
**控制要求**：第1周D5设计确认后立即下单；第2周D5前主要设备必须到货。若第2周未到货，第3周继续布线，第4周安装顺延，终验可能延至第7周。

**建议缓冲**：  
- 采购缓冲：2-3天；  
- 联调缓冲：1-2天；  
- 试运行整改缓冲：1-2天。

**每日管理**：施工日报 + 每日站会10分钟；每周五出周报，对照里程碑纠偏。
