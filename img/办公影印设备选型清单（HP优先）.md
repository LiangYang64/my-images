# 办公影印设备选型清单（HP 优先）

> 依据办公实际需求：广告彩页打印/复印、客户调查单扫描、大幅面画报打印、办公文档黑白打印、5 联式工单打印、出货单粘贴条码打印，以及**网络打印/扫描/存储、部门与员工权限管控和统计**。选型以 **HP（惠普）** 为主，仅 HP 无对应产品线的环节（针式、条码标签、管控软件）采用第三方并标注。参数以 HP 官网/经销商在售型号为准。

## 一、需求拆解 → 设备承担关系

| 办公需求 | 承担设备 | 品牌 |
| :--- | :--- | :--- |
| 广告彩页打印和复印 | A3 彩色激光多功能一体机 | **HP** |
| 客户调查单的扫描（量大） | 同上（高速 ADF 双面扫描 + 扫描到网络） | **HP** |
| 大幅面的画报打印 | 大幅面打印机（A0/36 英寸） | **HP** |
| 办公文档黑白打印（量大） | 黑白激光打印机（与彩机分流，降单页成本） | **HP** |
| 5 联式工单打印 | 针式打印机（复写/压感纸，1+4 联以上） | 第三方（HP 无针式产品线） |
| 出货单的粘贴条码打印 | 条码标签打印机（热敏/热转印） | 第三方（HP 无工业条码机） |
| 网络打印 / 扫描 / 存储 | 全部 HP 设备联网 + 扫描到 NAS/SMB 共享 | **HP** + 已有 NAS |
| 部门、员工权限管控与统计 | HP 内置安全/计数功能 + 可选管控软件 | **HP** + 第三方软件 |

### 6. 权限管控、统计与网络存储方案

| 能力 | 实现方式 | 说明 |
| :--- | :--- | :--- |
| 网络打印/扫描 | 全部设备接入办公网络（VLAN 10），安装网络驱动 | 员工凭工位电脑直接打印 |
| 扫描到网络存储 | MFP 配置「扫描到 SMB 文件夹」，目标为办公室 NAS 共享目录 | 客户调查单扫描件自动归档到 NAS，按部门建目录 |
| 部门/员工权限 | **HP Secure Print**（凭 PIN 到设备取件，防错拿/泄密）；**HP Access Control**（刷卡/账号认证，限定可用的功能与设备） | 需配置 HP 认证附件（刷卡器）或账号列表 |
| 用量统计 | **HP Job Accounting**（按部门/员工计数）；**HP Web Jetadmin** 集中管理设备与报表 | 输出月度部门/个人打印统计，便于成本分摊 |
| 强化管控（可选） | 第三方 **PaperCut**（配额、黑白/彩色计费、权限分组、报表审计） | 预算充足或管控要求高时启用 |

## 三、部署与实施建议

1. **设备联网**：M776、M608、DesignJet T650 均接入办公接入交换机（TL-SG2226，VLAN 10）；针式与条码机就近接入办公网并共享。
2. **扫描归档**：在 NAS 上创建「扫描件 / 部门目录」，MFP 预设扫描模板（黑白 PDF / 彩色 PDF / 可搜索 PDF），客户调查单整摞放 ADF 一键扫描归档。
3. **权限落地**：先启用 HP Secure Print + Job Accounting（零额外成本）；如需刷卡认证，再采购 HP 刷卡附件或评估 PaperCut。
4. **耗材**：彩色墨粉/硒鼓为最大可变成本，建议按印量核算单页成本；黑白文档强制走 M608 分流。
5. **采购核对**：型号以 HP 官网在售为准（M776/M608/T650 均为在售系列名），针式、条码、管控软件以经销商方案为准。
